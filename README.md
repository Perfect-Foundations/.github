# Perfect Foundations GitHub Configuration

This repository owns the organization-wide GitHub profile and shared community-health configuration for **Perfect Foundations**.

## Contents

- `profile/README.md` — public organization overview.
- `CONTRIBUTING.md` — shared contribution guidance.
- `SECURITY.md` — shared security-reporting guidance and claim boundaries.
- `SUPPORT.md` — family-level support routing.
- `PULL_REQUEST_TEMPLATE.md` — default pull-request checklist.
- `.github/ISSUE_TEMPLATE/` — shared architecture and bug-report templates.
